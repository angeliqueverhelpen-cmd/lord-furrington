# lord-furrington
A gentleman's game of blackjack.
Meet Lord Furrington: an aristocratic feline who believes that good manners, a stiff upper lip, and a winning hand are the foundations of a respectable life.
Unfortunately, his opponents don't always share his standards

ABOUT THE PROJECT:
Lord Furrington is a blackjack game and a personal learning project. It will be developed step by step while exploring full-stack development, DevOps, and AI.

PLANNED FEATURES:
Blackjack gameplay
Card and score display
Lord Furrington's reactions to the game (AI integration)
A distinctive visual style
Responsive layout
Automated code checks with GitHub Actions
Deployment

TECH STACK:
The technologies will be added as the project develops.

LEARNING GOALS:
Practice HTML, CSS, and JavaScript.
Learn Git and GitHub workflows
Experiment with automated testing and CI/CD
Build and deploy a complete full-stack project

STATUS: IN DEVELOPMENT
